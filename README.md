ResearchMind — Multi-Agent AI Research Pipeline

●	Built a 4-stage autonomous pipeline (LangChain + OpenAI GPT-4o-mini) with dedicated search, scraping, writing, and critique agents that research and draft reports on any topic.
●	Integrated the Tavily search API and BeautifulSoup-based scraping as agent tools, with a critic chain that scores and reviews each generated report;deployed via a custom Streamlit UI.
●	Tech: Python, LangChain, OpenAI API, Tavily API, Streamlit, BeautifulSoup.
